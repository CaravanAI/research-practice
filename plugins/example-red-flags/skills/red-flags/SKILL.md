# Red flags in an annual report

Use this when someone wants warning signs from an annual report.

1. Find out which folder to use. If the user did not name one, ask: "Which folder has the report?" Do not guess and do not look in other folders.
2. Hand the folder to the `red-flag-reader` agent from this plugin. Tell it to read only that folder.
3. Show the agent's list as it comes back. Each item must have a file, a page, and one label: Sourced, Inferred or Not in the sources.
4. Do not add buy, sell or hold views of your own.
5. Offer one follow-up: "Want me to turn the Sourced items into a research card?"
